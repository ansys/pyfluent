Move the settings state value types (`StateType` and related aliases) into the `ansys.framework` platform layer and repoint the settings services to them, so the service contracts no longer depend on Fluent's object framework (`flobject`). `flobject` re-exports the names for backward compatibility (EPIC #4618, task 2.1). Extract the backend-neutral connection lifecycle (finalizer registry, shared monitor thread, exit signalling) and the `ErrorState`/`MonitorThread` helpers into a platform `ansys.framework.connection.Connection` base that `FluentConnection` now subclasses, with the moved names re-exported from `fluent_connection` for backward compatibility (task 2.3a). Extract the gRPC channel, request metadata, error state and version-detected service factory into a `GrpcTransport` that implements the platform `Transport` protocol; `FluentConnection` composes it and delegates to it (task 2.3b).
