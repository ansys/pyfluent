Add the `ansys.framework` platform namespace stub for the componentization of PyFluent (EPIC #4618), plus report-only import-linter contracts encoding the target layer and dependency rules and an optional `grpc` install extra. Record the componentization architecture decisions (namespace, layers, dependency rules, gRPC dependency and backward-compatibility policy) in the `ansys.framework` package documentation. Add the `ansys.framework.process` process-controller contract (`ProcessLauncher`, `ProcessHandle`, `Endpoint`, `ReadinessProbe` and `wait_until_ready`), which imports only the standard library, and move the generic process helpers used by the Fluent launchers into it (`FileUpdatedProbe`, `pid_exists`, `detached_process_kwargs`, `run_cleanup_script`, `app_data_root`); the old private names remain importable from their original modules. Add a launcher base-class hierarchy: the generic `ansys.framework.process.BaseLauncher` and the Fluent `FluentLauncher`, which `StandaloneLauncher`, `DockerLauncher`, `PIMLauncher` and `SlurmLauncher` now subclass to share argument resolution, defaults, gRPC security checks and case/lightweight-mode validation. Make `ansys.framework.process` a package with `slurm` (`SlurmScheduler`, `read_job_id`) and `container` (`run_docker_container`) submodules, add `background_process_kwargs` and `child_environment`, and use them from the Slurm, container and standalone launch paths. `PortNotProvided` now lives in `execution.launcher.error_handler` and is still importable from `fluent_connection`. Add `ansys.framework.transport.ServingProbe`, a readiness probe over any transport, and `GrpcTransport.readiness_probe()`, which Fluent's exit path and the watchdog now use instead of reading the gRPC health check directly; `utils.networking` imports gRPC only when it is used. Add `start_fluent_process()`, which starts Fluent locally and returns a `FluentProcess` handle without connecting, and a `fluent_process` argument to `connect_to_fluent()` that connects a session to it; a local `launch_fluent()` now runs these two steps. Add the generic `LocalProcess` handle and `SubprocessLauncher` to `ansys.framework.process` (`FluentProcess` builds on `LocalProcess`), and a test that starts, monitors and terminates a dummy server with `grpc` and `ansys.api` blocked.
