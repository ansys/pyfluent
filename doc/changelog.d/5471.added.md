Embed ``resilient_mode`` / ``resilient_config`` in every session ``from_*`` entry
point for full API consistency. In addition to ``from_install`` (and
``launch_fluent``), ``Solver.from_container``, ``Solver.from_pim`` and
``Solver.from_connection`` now accept ``resilient_mode=True`` and wrap the
resulting solver session in resilient mode via a single shared
``BaseSession._maybe_enable_resilient_mode`` helper. The flag is a no-op for
dry runs and for sessions without a settings service (e.g. meshing), so every way
of creating a session can opt into resilient mode the same way.
