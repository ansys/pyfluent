Add a native resilient execution runtime (``ansys.fluent.core.resilient``) that
makes solver workflows survivable without any dependency on ``fastmcp`` or the AI
layer. ``ResilientSolver`` wraps a (optionally pooled) solver session and offers
two-tier checkpoints with a unified undo/redo stack -- in-memory settings
snapshots for reversible changes and case/data file checkpoints for irreversible
commands (``iterate``, ``read_case``, ...). Non-catastrophic Fluent errors
(inactive target, out-of-range, disallowed value, wrong type) are classified and
automatically repaired-and-retried using live object introspection
(``is_active`` / ``allowed_values`` / ``min`` / ``max``). A configurable warm
session pool (default ``pool_size=1``) adds health monitoring via the
``FATAL_ERROR`` event plus a poll backstop, and on a fatal error promotes a warm
standby and replays the last good checkpoint onto it.
