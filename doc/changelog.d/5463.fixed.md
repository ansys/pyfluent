Prevent resilient mode from failing over on a non-catastrophic error whose text
merely mentions "fatal". Catastrophic classification -- the only thing that
triggers a session failover -- is now driven solely by the authoritative session
``ErrorState`` (set by the ``FATAL_ERROR`` event). The error-text heuristic no
longer escalates to ``FATAL``, so a recoverable or benign message that contains
the word "fatal" (for example a warning that a setting "may cause a fatal error")
is handled in place instead of exiting and promoting a standby session.
