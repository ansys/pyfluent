- Refactored `launch_fluent()` to use Fluent's native CLI flags (`-case`, `-data`, `-i`) for file handling instead of deferred client-side processing.
- Implemented truth table logic for handling `case_file_name`, `journal_file_names`, and `lightweight_mode` combinations.
- In lightweight mode with case files and no journals, mesh reads into background session and transparently replaces current session.
- When both case and journals are provided, both are passed to Fluent via CLI flags, delegating file ordering to Fluent's native handling.
- When lightweight mode is requested with journals, lightweight mode is automatically disabled with a warning, ensuring predictable behavior.
