Make the resilient-mode guided demo robust to example-data download failures.
The mesh is now resolved local-first: if ``mixing_elbow.msh.h5`` / ``solid.msh``
already exists in the working directory it is reused, and only otherwise is it
downloaded (and cached). A transient download error now raises a clear, actionable
message instead of aborting the demo mid-run -- in particular the ``--failover``
chapter no longer crashes when the example-data URL is briefly unavailable.
