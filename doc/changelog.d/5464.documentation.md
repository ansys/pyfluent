Add a resilient-mode solidification example
(``examples/00-fluent/modeling_solidification_workflow_resilient.py``). It mirrors
the standard Czochralski solidification workflow but launches with
``resilient_mode=True`` and demonstrates recovery from a real solver divergence:
the transient ``calculate()`` that advances to ``t = 5 s`` diverges and Fluent
raises a ``floating point exception``. In the standard example this unhandled
``RuntimeError`` aborts the whole script. In resilient mode the error is
classified as non-catastrophic (the session stays alive -- no failover, no new
Fluent session), the converged state captured by an earlier checkpoint is
restored with ``rewind_to``, and the transient advance is retried from there with
stabilized settings -- so the expensive steady-state and first transient results
are preserved instead of being lost.
