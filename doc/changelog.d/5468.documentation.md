Add a guided, colour-coded resilient-mode demo
(``examples/00-fluent/demo_resilient_mode.py``) and a design-details document
(``doc/source/user_guide/resilient_mode_design.md``). The demo walks through two
separate examples -- transparent auto-recovery plus undo/redo on a mixing elbow,
and automatic rollback of a diverging solve on a 2D solidification case -- printing
one "capability / action-in-Fluent" banner per event so a viewer can follow the
undo / redo / checkpoint / recovery / failover flow. The ``mixing_elbow``
resilient example is simplified to rely on the automatic behaviour (no manual
checkpoint/undo calls).
