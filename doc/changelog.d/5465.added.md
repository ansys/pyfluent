Resilient mode now records every successful operation on an undo/redo journal.
Each value set captures the current value (via ``get_state``) as its undo point
before applying the new one; on a recoverable failure the step is undone (the
captured value is restored), repaired, and redone, then recorded. The journal is
a single global timeline navigable with ``undo`` / ``redo`` and exposes the
applied operations as a replayable script. Subscribe to ``record`` / ``undo`` /
``redo`` events with ``ansys.fluent.core.resilient.on_journal_event`` (used by the
demo to surface the recovery cycle). ``Journal``, ``SetOp`` and ``CommandOp`` are
exported from ``ansys.fluent.core.resilient``.
