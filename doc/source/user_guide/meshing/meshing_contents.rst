================
Meshing workflow
================
PyFluent provides guided workflows for generating a volume mesh from CAD geometry.
These workflows are accessible through two interfaces: a PyFluent-native interface,
and the classic Python interface, which matches Fluent's journaling syntax. PyFluent
recommends using the PyFluent-native interface.
