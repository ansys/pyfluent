case_snapshot#

Capture the complete setup of a Fluent case and apply it to solver sessions.

Classes:

class ansys.fluent.core.solver.case_snapshot.CaseSnapshot(*args, **kwargs)#

Bases: object

A snapshot of the complete setup of a Fluent case: all its settings and its mesh.

Capture a snapshot once, with from_session() or from_file(), and apply it to any number of solver sessions with apply_to(). The snapshot is carried by a Fluent case file, Fluent’s own complete record of a case, so it includes settings that the settings API does not expose. The case file is handled for you, whether Fluent runs locally, in a container, or remotely through a file transfer service. Solution data is not included.

Examples

>>> import ansys.fluent.core as pyfluent
>>> snapshot = pyfluent.CaseSnapshot.from_session(solver)
>>> snapshot.apply_to(worker_1, worker_2)
>>> template = pyfluent.CaseSnapshot.from_file("elbow_setup.cas.h5")
>>> template.apply_to(refined_solver, include_mesh=False)

apply_to(*sessions, include_mesh=True)#

Apply this snapshot to one or more solver sessions.

The case of each session is replaced. By default, each session also gets the mesh of the snapshot. With include_mesh=False, each session keeps its current mesh, whose zone names must match those of the snapshot.

Every session is checked before any is changed, and several sessions are loaded in parallel.

Parameters:
*sessionsSolver

Solver sessions to apply the snapshot to.

include_meshbool, optional

Whether each session gets the mesh of the snapshot. The default is True. With False, each session keeps its current mesh.

Raises:
TypeError

If no session is given, or a session is not a solver session.

ValueError

If a session runs an older Fluent version than the one that wrote this snapshot, has a different dimension, or, with include_mesh=False, has a mesh with different zone names.

RuntimeError

If this snapshot is closed, a session cannot exchange files with the client, or, with include_mesh=False, a session has no mesh or cannot replace its mesh.

ExceptionGroup

If applying fails for some of several sessions. It holds the original error of each of them.

close()#

Delete the temporary copy of a snapshot captured from a session.

Snapshots created with from_file() never delete that file. Closing twice is harmless.
