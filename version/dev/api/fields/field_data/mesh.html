class ansys.fluent.core.fields.field_data.mesh.Element(_id, element_type, node_indices=<factory>, facets=<factory>)#

Bases: object

A single mesh cell containing topology and connectivity information.

For standard element types (e.g. hexahedron, tetrahedron), connectivity is stored in node_indices. For polyhedral elements, connectivity is stored as a list of Facet objects in facets.

Attributes:
_idint

Integer element ID assigned by the Fluent solver.

element_typeCellElementType

Shape of the element; see CellElementType.

node_indiceslist[int]

Zero-based indices into Mesh.nodes for standard elements. Empty for polyhedral elements.

facetslist[Facet]

Faces of the element for CellElementType.POLYHEDRON elements. Empty for standard elements.

class ansys.fluent.core.fields.field_data.mesh.Mesh(nodes, elements)#

Bases: object

Computational mesh for a Fluent zone, containing nodes and elements.

Returned by LiveFieldData.get_mesh(). The nodes array provides spatial coordinates indexed from 0, and the elements array stores connectivity referencing those node indices.

Attributes:
nodeslist[Node]

Ordered list of Node objects; element connectivity uses zero-based indices into this list.

elementslist[Element]

List of Element objects describing cell topology and connectivity.
