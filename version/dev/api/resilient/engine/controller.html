controller#

The resilient controller: all resilient state and behavior of one session.

Classes:

ResilientController(session, config, adapter, *)

Resilient state of one session: journal, checkpoints, recovery and failover.
class ansys.fluent.core.resilient.engine.controller.ResilientController(session, config, adapter, *, pool=None, journal_complete=False)#

Bases: object

Resilient state of one session: journal, checkpoints, recovery and failover.

The controller is created by enable_resilient_mode(); users interact with it through session.resilient.

Parameters:
sessionobject

The product session.

configResilientConfig

Resilient-mode configuration.

adapterResilientAdapter

The product adapter.

poolWarmSessionPool, optional

Warm standby sessions for failover.

journal_completebool, optional

Whether the journal records the session from its launch, so that a standby launched the same way can be brought to the same state by replaying it.

apply_query(method, args, kwargs)#

Handle a delegated read; fail over if the server died.

Reads have no side effects, so a read that fails because the server died is repeated on the standby that takes over.

Raises:
Exception

The error of the read when it is not caused by a dead server, or when no standby is configured.

rollback(name=None)#

Restore the newest checkpoint, or the newest one called name.

Newer checkpoints and the journal entries recorded after the restored checkpoint are discarded.

Raises:
CheckpointError

If no matching checkpoint exists or the restore fails.

Undo the most recent value write.
