streaming_services#

Provide streaming access to Fluent events, data, monitors, and transcripts.

The package includes common streaming-service support for registering callbacks and specialized streams for datamodel updates, field data, monitor values, server events, and transcript output. Event enums and event-info classes are also provided for identifying and handling Fluent notifications.
