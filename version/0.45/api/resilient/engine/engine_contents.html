engine#

Product-agnostic resilient-mode engine.

This package depends only on the Python standard library. It talks to a product exclusively through a ResilientAdapter, and its modules import each other with relative imports only, so it can move to a standalone distribution without code changes. A unit test enforces that no module here imports a product package.

class ansys.fluent.core.resilient.engine.CheckpointConfig(directory=None, keep_last=5, include_data=True)#

Bases: object

Where and how checkpoints are written.

Parameters:
directorystr or os.PathLike, optional

Directory for checkpoint files. For a server that shares the client file system, the default is resilient_checkpoints/<run-id> under the current working directory. For a remote or containerized server, the default is the server working directory (for a container, the folder mounted into it), and a directory you give is a path on the server (for a container, a path inside it). It must already exist, and every standby session must be able to read it.

keep_lastint, optional

Number of most recent checkpoints to keep. Older ones are deleted when the client can reach the files. The default is 5.

include_databool, optional

Whether to include solution data when the product supports it. The default is True.
