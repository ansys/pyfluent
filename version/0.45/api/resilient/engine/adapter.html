adapter#

The product seam of the resilient engine.

The engine never imports a product. Everything that differs between products – how a session reports a fatal error, which exceptions it raises, how a checkpoint is written and read, how a standby session is launched – is implemented by a subclass of ResilientAdapter.

ansys.fluent.core.resilient.engine.adapter.instance_attr(obj, name)#

Return obj.name without triggering __getattr__ fallbacks.

Product sessions often forward unknown attributes to their settings tree (and therefore to the server). Probing them with getattr would issue remote calls, so the engine reads its own bookkeeping attributes with this helper. Returns None when the attribute does not exist.
